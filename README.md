# Witto POS — Enterprise Point-of-Sale & Inventory Platform

Witto POS is a high-throughput, full-stack Point-of-Sale and inventory management system designed for enterprise retail operations and multi-warehouse environments. Engineered with a focus on high availability, strict sub-100ms API latency SLAs, and a clean corporate interface.

### 🚀 Key Features
* **Real-Time Stock Tracking:** Live telemetry monitoring for inventory levels with optimistic locking to eliminate stock drift.
* **Dynamic Invoice Engine:** Instant client-side and backend PDF invoice generation and transaction history logs.
* **Multi-Tier RBAC:** Granular role-based access control (Admin, Inventory Manager, Terminal Cashier).
* **Sales Analytics Dashboard:** Interactive telemetry metrics and sales performance visualization using Chart.js.
* **Corporate Office UI:** Minimalist, high-density dashboard layout built with React, Vite, and Tailwind CSS.

### 🛠️ Tech Stack
* **Frontend:** React 18, Vite, Tailwind CSS, Chart.js
* **Backend:** Node.js, Express REST API, Socket.io
* **Database:** PostgreSQL 15, PgBouncer
* **Infrastructure:** Docker, Docker Compose
